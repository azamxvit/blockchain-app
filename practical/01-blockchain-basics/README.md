# Практическая работа 1. Базовый блокчейн

## Цель

Понять, как поля блока связываются в цепочку, и увидеть последствия изменения данных.

## Подготовка

```bash
npm install
npm start
```

## Задания

1. Найдите в [исходнике](../../src/blockchain.ts) класс `Block` и подпишите назначение каждого поля.
2. Добавьте третий пользовательский блок и проверьте вывод.
3. Реализуйте метод `isChainValid()`, который проверяет:
   - `previousHash` текущего блока совпадает с `hash` предыдущего;
   - `hash` текущего блока совпадает с пересчитанным значением.
4. Измените `data` первого блока после его добавления и зафиксируйте результат проверки.

## Вопросы

- Почему генезис-блок не имеет настоящего предыдущего блока?
- Почему одного `hash` недостаточно для проверки всей цепочки?
- Какие данные стоит хранить в блоке, а какие лучше вынести отдельно?

## Результат

В README своей ветки добавьте вывод программы и короткий вывод: что именно делает цепочку связанной и проверяемой.
